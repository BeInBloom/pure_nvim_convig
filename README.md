## Elixir и Clojure

Mason устанавливает `elixirls` и `clojure_lsp` при запуске Neovim.

Для Elixir нужен установленный Elixir/Erlang (включая приложения `public_key` и `ssl`) и проект с `mix.exs`. ElixirLS запускает Dialyzer, показывает ошибки типов и предлагает `@spec`. На Arch Linux с модульным Erlang установите пакеты `erlang-public_key` и `erlang-ssl` (зависимости загрузятся автоматически).

Для Clojure нужен Java и проект с `deps.edn`, `project.clj` или другим маркером проекта. Clojure-lsp использует clj-kondo для диагностики и предоставляет навигацию, подсказки и переименование. Clojure не имеет встроенной статической типизации; если требуется именно проверка аннотаций типов, её нужно подключать отдельно в проекте.

Текущий файл обновляется после внешней записи по событию файловой системы, включая атомарную замену файла. Несохранённые изменения в буфере не перезаписываются. При возвращении в окно или в Neovim также выполняется `:checktime`.

## Форматирование Svelte через Prettier

`prettier-plugin-svelte` установлен один раз в Prettier от Mason, а не в каждый проект:

```sh
cd ~/.local/share/nvim/mason/packages/prettier
npm install prettier-plugin-svelte --no-save
```

`lua/plugins/formatting.lua` передаёт Prettier абсолютный путь до `plugin.js`, поэтому плагин работает из любого проекта. Если Mason обновит или переустановит Prettier, плагин пропадёт: повторите команду выше. Пока плагин отсутствует, конфиг просто не передаёт аргумент `--plugin`, и Svelte не форматируется (без ошибок в остальных типах файлов).
